# KlassKonnect for Windows

This public repository contains the official KlassKonnect Windows installer only.

## Download

[Download KlassKonnect for Windows](https://isy-developer.github.io/KlassKonnect-Desktop/KlassKonnectSetup.exe)

- Windows 10 or Windows 11
- 64-bit
- Current pilot version: 0.1.0

The KlassKonnect application source, infrastructure configuration and private credentials are maintained separately and are not published here.

Visit [klasskonnect.com](https://www.klasskonnect.com/) for product information and support.
